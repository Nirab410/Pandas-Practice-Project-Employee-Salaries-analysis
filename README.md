# Pandas Practice Project Employee Salaries Analysis

This is a beginner-level Pandas practice project created to revise and understand core data analysis operations using Python and Pandas.

The project uses a salaries dataset and focuses on basic data exploration, filtering, grouping, and summary analysis.

## Project Purpose

The main purpose of this notebook is to practice Pandas fundamentals and build confidence in working with tabular datasets.

This is not an advanced portfolio project. It is a learning/practice project created as part of my data analysis learning journey.

## Topics Covered

- Loading CSV data using Pandas
- Viewing dataset using `head()` and `tail()`
- Checking dataset shape
- Checking column information using `info()`
- Generating statistical summary using `describe()`
- Checking missing values
- Dropping unnecessary columns
- Filtering rows based on conditions
- Working with string-based filtering
- Finding unique values and value counts
- Using `groupby()` for grouped analysis
- Calculating average, maximum, and minimum values
- Finding common job titles

## Tools Used

- Python
- Pandas
- NumPy
- Jupyter Notebook / VS Code
